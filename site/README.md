# ClickMate Site

Официальный лендинг ClickMate на Next.js. Проект находится отдельно от Android, Windows и локального PWA-клиента.

## Запуск

```powershell
npm install
npm run dev
```

Production-сборка создаётся командой `npm run build`. Vercel настроен на корневую папку `site` и автоматически публикует изменения из ветки `main`.
