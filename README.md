# ClickMate

Пульт для Windows с телефона в общей сети Wi-Fi. ClickMate 0.12.0 включает Android-приложение и мобильный веб-пульт, запоминает доверенные устройства, автоматически подключается после перезапуска ПК, поддерживает перетаскивание объектов мышью, оформление кнопок, поиск ПК в сети и запуск Windows-программы сразу в трее.

Официальный сайт: [clickmate-site.vercel.app](https://clickmate-site.vercel.app) — демонстрация приложения и загрузка программы для Windows. Android-приложение: [RuStore](https://www.rustore.ru/catalog/app/ru.ladon.remote).

## Готовые приложения

- `dist/ClickMate-PC.exe` — программа для Windows 10/11 x64, требуется .NET Framework 4.x (обычно уже есть в Windows).
- `dist/ClickMate-Android.apk` — приложение для Android 8.0 и новее, тестовая подпись.
- `web` — устанавливаемая PWA-версия мобильного пульта, подготовленная для публикации на Vercel.

## Подключение

1. Запустите `ClickMate-PC.exe` на компьютере. В окне появятся локальный IP-адрес и четырёхзначный код.
2. Если Windows предложит разрешить сетевой доступ, разрешите его для **частной сети**.
3. Передайте `ClickMate-Android.apk` на телефон и установите. При необходимости разрешите установку из используемого файлового менеджера.
4. Подключите телефон к той же сети Wi-Fi, что и ПК. ПК также может быть подключён кабелем к тому же роутеру.
5. Нажмите **«Ввести код»**: приложение само найдёт доступные компьютеры в сети. Выберите ПК и укажите четыре цифры с его экрана. Также можно нажать **«Сканировать QR»** или ввести адрес вручную.
6. Выберите нужное окно на ПК и управляйте им с телефона.

После первого успешного подключения телефон получает длинный случайный ключ доверия. Четырёхзначный код после этого не требуется: приложение подключается автоматически, в том числе после перезапуска компьютера и смены PIN. При повторном подключении сам ключ по сети не передаётся — телефон подтверждает его с помощью одноразового запроса. Можно запомнить до восьми телефонов и браузеров. Для полного отзыва доступа нажмите **«Забыть доверенные устройства»** в Windows-программе.

### Веб-пульт / PWA

1. Установите свежий `dist/ClickMate-PC.exe` и запустите его.
2. На телефоне в той же сети откройте адрес **«Веб-пульт»**, показанный в окне ClickMate, например `http://192.168.0.199:48732/`.
3. Введите четырёхзначный код только при первом подключении. Браузер сохранит отдельный ключ доверия и в дальнейшем подключится автоматически.

В веб-пульте есть тачпад с перетаскиванием и прокруткой, клавиатура, медиакнопки, собственная панель с кнопками шириной в одну, две или три ячейки, выбором цвета, а также светлая и тёмная темы. Настройки и панель хранятся локально в браузере.

В локальной сети веб-пульт работает по HTTP и его можно добавить на главный экран как ярлык. Полная установка PWA и офлайн-оболочка включаются после публикации по HTTPS. Для будущего размещения на Vercel задайте корневую папку проекта `web`; конфигурация `web/vercel.json` уже добавлена. Опубликованная HTTPS-версия пока не сможет напрямую открыть нешифрованное локальное WebSocket-соединение с ПК — перед публикацией рабочего удалённого управления потребуется добавить защищённый мост `wss://`.

Адреса подписаны Wi-Fi/Ethernet; известные VPN и виртуальные адаптеры скрыты. Если физических подключений несколько, выбирайте сеть, к которой подключён телефон.

### Вход через обычную камеру телефона

QR содержит ссылку `clickmate://connect?ip=…&pin=…`. Если системная камера или QR-сканер поддерживает открытие ссылок приложений, нажмите предложенную ссылку: откроется ClickMate и сразу подключится. Старые ссылки `ladon://` тоже поддерживаются. Если системная камера не распознаёт этот тип ссылки, используйте встроенную кнопку **«Сканировать QR»**.

QR создаётся и распознаётся локально, без внешних сервисов. Код действителен, пока в окне ПК включён текущий доступ. Отключение/повторное включение меняет PIN и QR. При выборе другого адреса в списке QR также обновляется.

Сворачивание или крестик окна Windows скрывают его в трей: подключение продолжает работать. Двойной щелчок по значку или пункт «Открыть ClickMate» возвращает окно. Для полного закрытия выберите «Выход» в меню значка правой кнопкой мыши.

Чтобы пульт был готов сразу после входа в Windows, включите в окне программы флажок **«Запускать вместе с Windows · сразу в трее»**. Настройка применяется только к текущему пользователю и не требует прав администратора. Отключение флажка удаляет запись автозапуска. Программа не устанавливает службу и не создаёт скрытых заданий планировщика.

Повторный запуск программы Windows открывает существующее окно, не создавая второй сервер. Если остался процесс старой версии, закройте его один раз через диспетчер задач.

## Управление

Разделы сверху можно прокручивать горизонтально. Настройки и создание своих разделов доступны даже без подключения к ПК.

- **Мышь**: большой тачпад, левый, правый, средний и двойной щелчки, переключение окон и рабочий стол.
- **Фильм**: компактный пульт с громкостью, переключением, паузой и тачпадом на одном экране.
- **Клавиатура**: ввод текста, клавиши навигации, копирование, вставка, вырезание, отмена, повтор, поиск и сохранение.
- **Медиа**: громче/тише, отключение и включение звука, пуск/пауза, предыдущий/следующий трек, стоп. Используются стандартные [медиаклавиши Windows](https://learn.microsoft.com/en-us/windows/win32/inputdev/virtual-key-codes). Реакция зависит от поддержки клавиш плеером; процент громкости и название трека не считываются.
- **Навигация**: вкладки браузера, назад/вперёд, масштаб, полный экран, управление презентацией и окнами. Сочетания применяются к активному окну ПК.
- **Настройки**: чувствительность мыши, скорость и направление прокрутки, щелчок касанием, тактильный отклик, тёмная тема и удержание экрана включённым во время подключения.

### Свои разделы

1. Прокрутите верхнюю строку разделов и нажмите **«+ Раздел»**, либо откройте **Настройки → Создать раздел**.
2. Введите название, добавьте команды из каталога или кнопки с собственным текстом. Для добавления тачпада выберите **Добавить команду → Мышь → Тачпад**.
3. В редакторе кнопки располагаются в **3 колонки**. Нажмите кнопку, чтобы выбрать ширину в одну, две или три ячейки, иконку и цвет. Удерживайте кнопку и перетащите на нужную ячейку: пустая ячейка останется свободной, а при переносе на другую кнопку они поменяются местами. У края списка работает автопрокрутка. Нажмите **«Сохранить»**.
4. Нажатие на кнопку в редакторе открывает изменение текста, выбор позиции или удаление. Тачпад занимает всю ширину — три колонки — и тоже перемещается в редакторе.
5. Новый раздел появится в верхней строке. Редактирование и удаление с подтверждением доступны в **Настройки → Свои разделы**; на самой панели остаются только элементы управления.

Чувствительность мыши по умолчанию — 1×. В редакторе пустые ячейки обозначены «＋», на пульте они невидимы. Пустые места сохраняются, удаление кнопки не сдвигает соседние.

Можно создать до 12 разделов по 24 элемента (кнопки и тачпады). Название — до 30 символов, текст кнопки — до 1000 символов. Разделы и настройки сохраняются на телефоне между запусками и обновлениями APK. Старые панели автоматически отображаются в три колонки с сохранением всех кнопок. Удаление приложения очищает данные.

### Порядок разделов

Удерживайте название раздела сверху или откройте **Настройки → Порядок разделов**. Перетащите раздел на нужное место и нажмите **Сохранить**. Можно перемещать и стандартные, и свои разделы. Обычное нажатие на плитку позволяет выбрать номер позиции без перетаскивания. «Отмена» оставляет прежний порядок.

### Жесты и подключение

- Провести одним пальцем по тачпаду — переместить мышь.
- Быстро коснуться — левый щелчок; два последовательных касания — двойной щелчок.
- Коснуться, затем быстро коснуться ещё раз и вести палец — удерживать левую кнопку и перетаскивать окно, файл или другой объект. При отпускании пальца кнопка мыши отпускается.
- Провести двумя пальцами — прокрутить.
- Удержать палец на месте дольше половины секунды и отпустить — правый щелчок.
- «Левый щелчок» / «Правый щелчок» — кнопки мыши.
- Набрать текст на телефоне и нажать «Ввести текст» — отправить его в активное окно Windows. Поддерживается кириллица.
- Доступны Enter, Backspace, Tab, Esc, стрелки, пробел, Delete и сочетания копирования, вставки, выделения и отмены.
- «Отключить доступ» на ПК немедленно закрывает соединение. Повторное включение создаёт новый код, но доверенный телефон по-прежнему может подключиться без него.
- «Забыть доверенные устройства» отзывает автоматический доступ всех сохранённых телефонов и браузеров и отключает активное соединение. Следующее подключение потребует новый четырёхзначный код.
- При сворачивании приложения на телефоне связь закрывается; после возврата доверенное устройство подключается автоматически.

Для обновления с 0.1.x/0.2.x обновите обе части. APK устанавливается поверх предыдущего с сохранением данных. Новое приложение Android подскажет, если программа на ПК ещё не поддерживает разделы.

В этой версии нет трансляции экрана, передачи файлов и удалённого запуска команд.

## Если телефон не подключается

Проверьте адрес и общую сеть. Для первого подключения или после отзыва доверия проверьте также код. Гостевая Wi-Fi-сеть может запрещать соединения между устройствами. VPN также может мешать локальному подключению.

Для управления используется TCP-порт **48732**, для поиска ПК — UDP-порт **48733**. Если доступ блокирует брандмауэр, для доверенной домашней сети можно запустить `allow-firewall.ps1` от имени администратора. Скрипт разрешает только входящие соединения из локальной подсети в профиле «Частная сеть»; автоматически при сборке он не выполняется. Не отключайте брандмауэр целиком.

## Ограничения и защита

- Принимается только один телефон за раз; до проверки кода или ключа доверия команды не выполняются.
- После пяти неверных кодов или подтверждений доверия действует пауза 30 секунд.
- Команды и размеры сообщений ограничены; функции выполнения программ и команд оболочки отсутствуют.
- Соединение локальное и **без шифрования**: используйте доверенную домашнюю сеть. Постоянный ключ не передаётся при автоматическом подключении, однако команды и вводимый текст могут быть доступны тому, кто способен перехватить трафик этой сети. Не открывайте порт на роутере в интернет.
- Обычное приложение не управляет окнами с повышенными правами и защищённым экраном UAC. Некоторые игры также не принимают эмулированный ввод. См. [документацию Microsoft SendInput](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput).
- APK собран и его подпись проверена. Проверены протокол Windows, создание/редактирование/удаление своих разделов на Android-эмуляторе, распознавание созданного Windows QR библиотекой сканера и автоматическое подключение эмулятора к реальному ПК по ссылке. Новые функции с физической камерой телефона ещё не проверены.

## Исходники и сборка

`android` можно открыть как проект в Android Studio. Проект использует Android SDK 35 и Android Gradle Plugin 8.13.0.

Для воспроизводимой сборки без скачивания Gradle используйте PowerShell из корня проекта:

```powershell
.\build-windows.ps1
.\build-android.ps1
.\test-windows.ps1
```

Android-скрипт использует установленные Android Studio JBR, SDK Platform 35 и Build Tools 35.0.0. При нестандартных путях передайте `-Sdk` и `-Java`. Тестовый ключ создаётся в `build/debug.keystore`: сохраните его, чтобы обновления APK устанавливались поверх предыдущей сборки. Для публичного выпуска нужен отдельный релизный ключ.

Тесты используют свободный временный порт и не мешают запущенному пульту. Они проверяют авторизацию, HTTP-выдачу PWA, браузерное WebSocket-подключение, ограничения команд, отключение, повторный запуск, защиту от перебора, соответствие медиаклавиш и отпускание модификаторов сочетаний; не отправляют реальный ввод в ваши окна.

Исходники Windows находятся в `windows/RemotePc.cs`, Android — в `android/src/ru/ladon/remote/MainActivity.java`, PWA — в `web`.

QR-библиотеки закреплены локально в `third_party`: QRCoder 1.6.0 (MIT) и ZXing Core 3.5.3 (Apache-2.0). Сборка не обращается к интернету. Лицензия QRCoder включена в EXE, ZXing — в APK и исходники.
